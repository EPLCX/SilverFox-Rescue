# 银狐专杀急救箱

面向 Windows 7–11 x64 的中文恶意软件应急扫描工具。它检查文件、进程、服务、自启动项，以及 hosts、IFEO、代码完整性策略等系统配置，列出每一项的判定与检测依据，由你确认后统一处置。被处置的文件进入隔离区，可以恢复。

**主要特点**

- **多种扫描方式**：快速扫描、全盘扫描、自定义目录扫描、进程扫描、服务扫描。
- **结果透明**：每一项都显示判定和检测依据。
- **先确认再处置**：恶意项默认勾选，可以调整选择后统一处理。
- **可核验、可恢复**：处置前重新核验文件；处置后的文件进入隔离区，可以恢复。
- **可追溯**：扫描和处理动作写入审计日志，结果可导出为 JSON 报告。
- **更新有签名**：程序包与规则包通过 HTTPS 分发，客户端核验包哈希、签名及产品信息后安装。

## 使用指南

### 快速开始

1. **获取程序。** 从 [官方网站](https://www.sf-rescue.top/) 或 Releases 页面下载发布版本的 `silverfox-rescue.exe`，或按[构建](#构建)自行编译。
2. **以管理员身份运行。** 双击程序，在 UAC 提示中允许。
3. **等待更新。** 启动后先进入更新阶段（默认更新站点见[签名与发布](#签名与发布)）。更新实际完成后即可开始扫描，界面何时切换取决于更新的展示时间。
4. **选择扫描方式。** 需要尽快排查时，先做快速扫描。
5. **查看结果。** 逐项查看判定和检测依据，不确定的项目可以取消勾选。
6. **处置。** 对勾选项统一处置。部分文件需要重启才能完成删除。
7. **善后。** 需要留档时导出 JSON 报告；误处置的文件可以从隔离区恢复。

### 扫描方式

| 方式 | 检查内容 | 适用场景 |
| --- | --- | --- |
| 快速扫描 | 重点目录、运行进程、服务映像、自启动项和系统配置（详见[下文](#快速扫描检查内容)） | 首次排查 |
| 全盘扫描 | 磁盘上的全部文件 | 需要全面检查时 |
| 自定义目录扫描 | 你指定的目录 | 怀疑某个目录时 |
| 进程扫描 | 正在运行的进程 | 怀疑有恶意进程在运行时 |
| 服务扫描 | 服务映像；解析 `ImagePath`、`ServiceDll` 和受支持的间接启动命令 | 怀疑恶意服务时 |

恶意进程映像所在目录的同级文件会纳入扫描。

#### 快速扫描检查内容

**目录**（不存在的目录直接跳过）

- 重点目录：`C:\ProgramData`、`C:\Program Files (x86)`、`C:\Program Files`、`C:\Windows\Temp`、`C:\Windows\SystemTemp`、`C:\Users\Public`、`C:\inetpub\wwwroot`
- 存在时才扫描：`C:\Drivers`、`C:\Temp`、`C:\Program Files(x86)` 和启动目录
- 当前用户的桌面和 Temp 目录

**系统位置**

- **运行中的进程**和**服务映像**。
- **注册表启动项**、**启动目录中的快捷方式**和**计划任务**：系统自动运行程序的常见位置。
- **hosts 文件**（本机域名解析表）：出现非 localhost 的有效映射，即报告为恶意。
- **IFEO**（映像文件执行选项，可让程序启动时被替换为另一个程序）：检查实际生效的重定向。
- **代码完整性策略**（`System32\CodeIntegrity` 下的策略文件，控制哪些程序可以运行）：按强制执行场景中实际引用的拒绝路径、文件身份和拒绝签名者条件，识别安全软件是否被阻断；不使用策略文件的哈希黑名单。

hosts 和代码完整性策略由签名 DLL 判定。

### 读懂扫描结果

结果列表显示每一项的判定和检测依据。恶意项默认勾选，你可以调整选择后统一处理。

- **家族标签**：PE 文件（EXE、DLL 等 Windows 可执行文件）的家族显示为 `Trojan.家族名.置信度`。置信度为两位十六进制数，每增加 `01` 表示增加 0.5 个百分点。
- **判定方式**：PE 文件由 LightGBM 模型根据文件内容的字节分布、熵及 PE 结构等特征判定，输出恶意概率和家族名称，详见[检测模型](#检测模型)。
- **其他文件类型**：PNG 附加数据检测与 ZIP/MSI 内部文件扫描由各自流程处理。
- **不支持的文件**：不支持检测的文件不会列入未完成检测报告。
- **进度**：更新等待与文件统计阶段显示滚动进度条；正式检测阶段按已处理文件数显示进度。

### 处置与恢复

被处置的文件进入隔离区，位置见[文件位置](#文件位置)。

**处置**

- 处置前重新核验文件。
- 查找并处理关联进程、文件占用和权限阻碍。
- 隔离失败最多尝试三次。
- 需要重启才能完成删除的文件，保留隔离副本并登记相应状态。

**特殊项目**

| 项目 | 处置方式 |
| --- | --- |
| hosts、IFEO | 核对扫描时的内容，保存备份后修改对应配置 |
| 恶意的代码完整性策略 | 进入加密隔离区，重启后完成策略解除 |

**恢复**

恢复时会核验隔离数据，并检查原路径是否已存在文件。

### 权限与进程保护

- 客户端通过 UAC 请求管理员权限。启动时验证内嵌算法包和已配置的程序签名。
- 进程保护使用受保护 DACL、进程缓解策略和 `Protect` 驱动。
- 正常关闭时解除进程保护并停止驱动。

### 界面与无障碍

主窗口支持 Per-Monitor V2 高 DPI、自绘标题栏及按钮、原生无障碍接口和局部绘制。

| --- | --- |
| 隔离区 | `%ProgramData%\SilverFoxRescue\quarantine`（扫描跳过该目录） |
| 审计日志 | `%ProgramData%\SilverFoxRescueLogs` |

### 常见问题

**为什么需要管理员权限？**

扫描和处置涉及系统目录、服务、注册表启动项、计划任务和系统策略文件，需要较高权限。客户端启动时通过 UAC 请求管理员权限。

**会不会误处置正常文件？**

处置前你可以取消勾选不确定的项目。处置时程序会重新核验文件，被处置的文件进入隔离区，之后可以恢复。

**文件被占用或没有权限，处置不了怎么办？**

程序会查找并处理关联进程、文件占用和权限阻碍，隔离失败最多尝试三次。仍需重启才能删除的文件会保留隔离副本并登记状态。

## 开发指南

### 技术组成

| 组件 | 技术 | 职责 |
| --- | --- | --- |
| 客户端 `silverfox-rescue.exe` | Rust、原生 Win32 窗口、C++ 扫描引擎 | 扫描、处置、隔离恢复、报告导出；同一 EXE 的内部模式负责程序更新 |
| 检测模型 | LightGBM | PE 文件多分类，使用 327 个特征 |
| 进程保护 | 受保护 DACL、进程缓解策略、`Protect` 驱动 | 保护客户端进程 |
| 更新站点 | nginx 静态发布、HTTPS | 分发已签名的程序包与规则包 |

### 仓库导览

| 路径 | 内容 |
| --- | --- |
| `build.ps1` | 构建脚本 |
| `dist/` | 构建输出，如 `silverfox-rescue.exe` |

| `driver/` | `Protect` 驱动及构建说明 |

### 构建

**环境**

- Rust 工具链
- PowerShell
- Python（运行 `tools` 下的发布与训练脚本）
- WDK（仅在生成驱动时需要）

构建脚本从进程、用户或系统环境变量读取 `CARGO_TARGET_DIR`，并在该目录下放置编译与临时文件；目标目录须位于 D 盘。驱动中间文件也使用同一个目标目录。

```powershell
# 可按需设置本次会话的输出目录；未设置时读取用户或系统环境变量
$env:CARGO_TARGET_DIR = '<目标目录>'

# 构建
.\build.ps1

# 运行构建产物
.\dist\silverfox-rescue.exe
```

生成驱动 SYS、INF 和 CAT 时使用 `build.ps1 --build-dll`，需要已安装的 WDK：

```powershell
.\build.ps1 --build-dll
```

### 签名与发布

**配置项**

| 配置项 | 作用 | 说明 |
| --- | --- | --- |
| `SILVERFOX_CLOUD_URL` | 构建时指定更新站点地址模板；每个 `*` 在程序每次运行时替换为随机字母或数字 | 默认 `https://***.sf-rescue.top`，运行时环境变量不覆盖构建配置 |
| `SILVERFOX_RULE_PUBLIC_KEY_HEX` | 注入规则公钥 | 也可由 `rules-public.hex` 提供 |
| `SILVERFOX_PROGRAM_PUBLIC_KEY_HEX` | 注入程序公钥 | 也可由 `program-public.hex` 提供 |
| `SILVERFOX_KEY_DIR` | 公钥文件目录 | 构建脚本从中读取 `rules-public.hex` 和 `program-public.hex`；默认 `releaseSecrets` |

**标准发行流程**

1. 编译并签名算法 DLL
2. 生成规则包
3. 编译 EXE
4. 生成程序 ZIP 和更新清单

交互入口：

```powershell
python tools\sign_program.py
```

私钥由发布工具读取。EXE 构建后直接输出；程序 ZIP 与规则包继续采用 Ed25519 签名和哈希校验。签名流程见 [SELF_SIGNING.md](SELF_SIGNING.md)。

### 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--verify-update-package <package.zip> <program-manifest.json>` | 核验更新包 |
| `--health-check` | 健康检查 |

程序更新由同一 EXE 的内部模式协调退出、替换和回滚。

### 检测模型

- **特征**：从文件内容提取字节分布、熵及 PE 结构等特征，模型共使用 327 个特征；输入上限为 256 MiB。
- **模型**：LightGBM 多分类，输出恶意概率和家族名称。显示格式见[读懂扫描结果](#读懂扫描结果)。
- **GPU 加速**：Direct3D 11 Compute Shader 可加速字节直方图统计；GPU 不可用或统计校验失败时使用 CPU。
- **训练**：入口为 `tools/train_lightgbm.py`，生成 `engine/ml_model.generated.h` 和 `model/static_ml_report.json`。训练标签、分组评估和原生一致性检查流程见 [model/README.md](model/README.md)。
